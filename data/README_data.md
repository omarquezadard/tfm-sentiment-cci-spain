# Data

## Consumer Confidence Index — Spain (included)

`cci_spain.csv` is a filtered and cleaned subset of the Eurostat dataset **`ei_bsco_m`** (Consumer Confidence Indicator, monthly), covering Spain from March 2024 to March 2026 with seasonal adjustment applied.

**Download the full raw dataset:**

1. Go to [Eurostat Data Browser — ei_bsco_m](https://ec.europa.eu/eurostat/databrowser/view/ei_bsco_m)
2. Select: Country = Spain · Indicator = Consumer Confidence Indicator · Adjustment = Seasonally adjusted
3. Export as CSV (`ei_bsco_m_linear.csv`)
4. Place it in this `/data/` folder
5. Run Section 2 of the notebook to reproduce `cci_spain.csv`

## Tweets — @_minecogob (NOT included)

Raw tweet data cannot be redistributed under the [X Developer Agreement](https://developer.x.com/en/developer-terms/agreement-and-policy). To reproduce the extraction:

### Prerequisites

- An active X Developer account with **Basic or Pro access** (the Free tier does not include user timeline endpoints).
- A **Bearer Token** from your app at [developer.x.com](https://developer.x.com).

### Steps

```bash
# 1. Set your Bearer Token as an environment variable (never hardcode it)
export X_BEARER_TOKEN="AAAAAAAAAAAAAAAAAAAAAxxxxxx..."

# 2. Open the notebook and set RUN_EXTRACTION = True in Section 1
# 3. Run Section 1 — the script will paginate through @_minecogob's timeline
#    (user ID: 494041400) and save tweets_minecogob.csv
```

The extraction script (in the notebook) uses:
- Endpoint: `GET /2/users/:id/tweets`
- Parameters: `exclude=retweets`, `start_time=2024-01-01`, `end_time=2026-03-31`
- Fields: `created_at`, `text`, `public_metrics`
- Pagination: up to 20 pages × 100 results = 2,000 max

### Expected output

After running the extraction, you should have `tweets_minecogob.csv` with approximately **1,100 rows** (before retweet filtering), which reduces to **716 original tweets** after preprocessing.
